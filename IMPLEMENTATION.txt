SYSTEM ARCHITECTURE

[1] Data Sources (Fiber telemetry, logs, alarms)
        ↓
[2] Data Translator Layer (LLM normalization)
        ↓
[3] Prediction Layer (ML anomaly detection)
        ↓
[4] Multi-Agent LLM System
        ↓
[5] Simulation Layer (Lightweight Digital Twin)
        ↓
[6] SDN Controller (Execution)
        ↓
[7] Explainability Interface (Human trust layer)


ARCHITECTURE FLOW

SimulationEngine
    ↓
Data Simulator (network state + faults)
    ↓
Anomaly Detector (fault detection)
    ↓
LLM Agent (context reasoning)
    ↓
Decision Engine (action planning)
    ↓
Validator + Executor (self-healing actions)
    ↓
Logger (history + analysis)

PIPELINE FLOW
from data_simulator import generate_network_data
from models.anomaly_detector import detect_anomalies
from core.decision_engine import process_decisions, validate_and_execute
from core.llm_agent import llm_reasoning

# 1. Generate data
df = generate_network_data()

# 2. Detect anomalies
df = detect_anomalies(df)

# 3. Decision engine (THIS decides actions)
df = process_decisions(df)

# 4. Get latest state
latest = df.iloc[-1]

# 5. Simulate action
simulation_result = {
    "status": "safe",
    "risk_score": 0.2
}

# 6. Validate execution
final_decision = validate_and_execute(latest, simulation_result)

# 7. LLM explanation
llm_output = llm_reasoning(latest)

print(final_decision)
print(llm_output["explanation"])
